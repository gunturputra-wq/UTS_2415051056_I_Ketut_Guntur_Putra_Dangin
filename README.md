# BookNest

BookNest adalah aplikasi Flutter untuk mencari buku, mengelola koleksi buku, dan mencatat aktivitas membaca.

## Fitur Utama
- Home dan Explore
- Pencarian buku melalui Open Library API
- Detail buku
- Koleksi buku
- Catatan membaca
- State management menggunakan Provider

## Teknologi
- Flutter dan Dart
- Provider
- REST API
- Open Library API

## Menjalankan Aplikasi
```bash
flutter pub get
flutter run
```
